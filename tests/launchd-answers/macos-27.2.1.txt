# launchd's own answers about a job's arguments, as recorded; read by the suite's G5.31 tests. Between a "print"
# line and the next "end-print" line stands what "launchctl print" gave for that job, as it was, but for what
# belongs to the machine or the account: the account's number in the job's domain, the number of its login
# session (in square brackets after the domain, and on the "asid" line) and each job's two "coalition"
# numbers stand here as the word NUMBER, and the random part of the session's socket folder as the word NAME.
# where: a Mac, macOS 27.2.1, in a test account that has a desktop session, asked over ssh
# when: 2026-11-25
# how: six trial jobs under trial labels of the recorder's own, each loaded once and run at load against a stand-in program. Two composed by this version's writer, for paths with a space, a percent sign, a dollar sign, both quotes, a backslash, an ampersand and angle brackets. Two by this version's writer for a path with an accented letter, once as one character and once as a letter and a combining mark. Two as the 0.1.10.3 writer composes them, with plain paths. Recorded answers for the reader, not a proof that setup runs there: the tool's own setup was not run on that Mac.
